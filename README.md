## 🚀 Cara Menjalankan Aplikasi (Contoh Week-10)

```powershell
# 1. Masuk ke folder pertemuan yang diinginkan
cd Week-10

# 2. Jalankan Expo Dev Server
npx expo start
```
- Tekan tombol **`w`** di terminal untuk membuka langsung di browser web laptop.
- Scan **QR Code** melalui aplikasi **Expo Go** di smartphone (Android / iOS).

*(Opsional untuk Week 4 s/d Week 10)*: Jalankan mock server API di terminal terpisah:
```powershell
npm run api
```
